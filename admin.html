Lee esto una vez

El usuario y la contraseña de este panel no son seguridad: están escritos en el código y cualquiera puede leerlos. Lo único que protege tu portafolio es el token — sin un token válido nadie puede guardar nada, aunque entre aquí.

El token se guarda solo en este navegador y únicamente viaja a api.github.com. En un equipo prestado, usa "Olvidar token" al terminar.

Cómo crear el token

  1. Entra en github.com/settings/personal-access-tokens/new (token fine-grained).
  2. En Repository access elige Only select repositories y marca únicamente portfolio.
  3. En Permissions → Repository permissions, pon Contents en Read and write. No hace falta nada más.
  4. Elige una caducidad (90 días es razonable) y genera el token.
  5. Cópialo y pégalo abajo. GitHub solo te lo enseña una vez.

Acotado así, si el token se filtrara solo daría acceso de escritura a este repositorio, a nada más de tu cuenta.
